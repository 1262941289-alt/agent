核心设计模式总结

1. 布局模式：2×2 网格（推荐）

Agent Village（Canvas）

像素画风格 Agent 状态可视化，工作/休息/完成动画

Monitor Panel（指标）

任务计数、Token 使用、上下文窗口、阈值标记

Ticket Tracker（任务）

里程碑进度条、点击展开详情、状态过滤

Activity Log（日志）

时间戳事件流、角色标签、类型图标、自动滚动

优势：信息密度高、模块化清晰、响应式友好。来源：multiagent-dashboard

4. 实时通信：SSE（推荐）

// 后端（Spring Boot） @GetMapping("/api/events") public SseEmitter streamEvents() { SseEmitter emitter = new SseEmitter(); // 发送事件 emitter.send(SseEmitter.event() .name("agent-status") .data(agentStatus)); return emitter; } // 前端（Vanilla JS） const eventSource = new EventSource('/api/events'); eventSource.addEventListener('agent-status', (e) => { const data = JSON.parse(e.data); updateAgentStatus(data); });

优势：浏览器原生支持、无需 WebSocket 库、自动重连、Spring Boot 内置 SseEmitter。 来源：multiagent-dashboard

sk-agent 前端改造建议

推荐方案：2×2 网格 + 信用分排行榜

Agent 状态总览

4 个能力域 Agent 卡片：browser / general / data / history，显示当前状态（Working/Idle/Error）、信用分、最近任务

执行过程流

当前 run 的实时事件流：run:started → run:plan → wave:started → step:status → run:completed

信用分排行榜

Agent 按信用分排序，显示 SSS/SS/S/A/B/C/D 等级、趋势指示器、历史图表（Chart.js）

系统指标

任务统计（成功/失败/反思次数）、平均耗时、Token 使用、上下文窗口、选举结果

技术栈：Vanilla JS + Chart.js（信用分图表）+ SSE（实时事件流），无框架依赖，易于集成到现有 Spring Boot 后端。

实施优先级

  1. P0：Agent 状态总览（4 个能力域 Agent 卡片，显示状态 + 信用分）
  2. P1：信用分排行榜（等级系统 + 趋势图 + 事件流）
  3. P2：执行过程流（当前 run 的实时事件流，已有基础）
  4. P3：系统指标（任务统计、Token 使用、选举结果）
